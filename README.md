Mini Quiz Game

A beginner-friendly Python quiz game that asks three questions, checks the user's answers, keeps track of the score, and displays the final result.

About the Project

I am a freshman undergraduate learning Python. This project is part of my beginner programming practice and focuses on variables, user input, conditional statements, comparison operators, and a simple score counter.

What the Program Does

Starts the score at 0.

Asks the user three questions.

Checks each answer using if/else.

Adds 1 to the score when an answer is correct.

Displays the final score.
